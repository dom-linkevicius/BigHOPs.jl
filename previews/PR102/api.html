BigHOPs.ASHA Type
julia
ASHA(; R, η=3, r_min=1, iterations=1, inner=RandomSampler())

Asynchronous Hyperband, with the same schedule and arguments: a trial is promoted as soon as it is among the best 1/η completed so far in its rung, instead of waiting for the rung to finish (Li et al., 2020, https://doi.org/10.48550/arXiv.1810.05934). This keeps workers busy under Threaded or DistributedQueue.

source
BigHOPs.BOHB Type
julia
BOHB(; R, η=3, r_min=1, iterations=1, ρ=1/3, q=0.15, N_s=64, N_min=nothing, b_w=3,
     min_bandwidth=1e-3, rng=StableRNG(1))

Hyperband's schedule with the first rung of each bracket drawn from kernel density estimates, following the paper (Falkner et al., 2018, https://arxiv.org/abs/1807.01774), with the details it leaves open taken from the reference implementation (https://github.com/automl/HpBandSter). Promotions are as in Hyperband.

A fraction ρ of draws, and every draw before a resource level has enough completed trials, is uniform at random. Otherwise the N completed trials at the largest such level are split into the best max(N_min, ⌊qN⌋) and the rest, and the draw is whichever of N_s samples from the good density, with bandwidths widened by b_w except on Nominal, has the highest ratio of good to bad density. N_min defaults to the number of hyperparameters plus one, and anything lower throws an ArgumentError.

BigHOPs.Continuous Type
julia
Continuous(min, max; transform=identity)

A real interval [min, max], passed through transform after sampling, so Continuous(-4, -1; transform=exp10) is log-uniform over [1e-4, 1e-1]. transform must be finite at both ends, and should be a named function rather than a closure if the optimizer will be checkpointed.

BigHOPs.DEHB Type
julia
DEHB(; R, η=3, r_min=1, iterations=1, F=0.5, crossover=0.5, rng=StableRNG(1))

Hyperband's schedule with differential evolution in place of random draws, following the paper (Awad et al., 2021, https://doi.org/10.24963/ijcai.2021/296), with the details it leaves open taken from the reference implementation (https://github.com/automl/DEHB).

The first rung of the first bracket is drawn uniformly at random, and every other first-rung trial is evolved from its own level's subpopulation, with a random target standing in for a slot that is still empty. In the first iteration, later rungs promote the best configurations from the level below unchanged; in later iterations every trial is evolved from the level below. Every trial trains from scratch: a Stateful objective never receives a pre_artefact and only has its post_artefact recorded.

BigHOPs.DistributedQueue Type
julia
DistributedQueue(max_concurrency=Sys.CPU_THREADS; spawn_worker, setup_worker=Returns(nothing), teardown_timeout=30, max_single_runtime=Inf, worker_metadata=Returns(NamedTuple()))

  • spawn_worker(): start one worker and return its process id, e.g. () -> first(addprocs(1)).

  • setup_worker(pid): prepare that worker before its trial, e.g. load packages and define the objective there.

  • teardown_timeout: seconds to wait when removing a worker.

  • max_single_runtime: seconds a trial's objective may run before its worker is killed and the trial marked TimedOut; the default Inf sets no limit. Also accepts a function of the trial's parameters, e.g. p -> 30 + 20 * p.r to scale with a successive-halving resource level; if it throws or returns a non-positive limit, that trial fails.

  • worker_metadata(): run on each trial's worker before its objective, returning a NamedTuple of extra details to record, e.g. () -> (job = ENV["SLURM_JOB_ID"],). They are stored as text in the trial's metadata[:worker], alongside the worker id, host, OS process id and start time; if it fails, the trial runs without them and the error is recorded as metadata_recording_error.

BigHOPs.DistributedQueue Type
julia
DistributedQueue(max_concurrency=Sys.CPU_THREADS; spawn_worker, setup_worker=Returns(nothing), teardown_timeout=30, max_single_runtime=Inf, worker_metadata=Returns(NamedTuple()))

Evaluate each trial on its own freshly spawned Distributed worker, up to max_concurrency at a time, removing the worker when the trial returns. Suited to clusters, where spawn_worker can request a process from a scheduler.

BigHOPs.GPSampler Type
julia
GPSampler(gp; next_point, noise, n_initial, initial=SobolSampler(), fit_hyperparams=nothing, standardize=BigHOPs.zscore, strict_initialization=true, rng=StableRNG(1))

Model the objective as a Gaussian process over the unit-encoded hyperparameters and let next_point choose each new trial once the initial trials are done. From then on, the GP is conditioned on every Completed trial after each tell; during the initial trials it is not. Nominal hyperparameters enter the kernel through their ordered unit encoding.

  • gp: an AbstractGPs prior, e.g. GP(Matern52Kernel()).

  • next_point(posterior, d, rng): return the next trial as a point in [0, 1]^d, e.g. ThompsonSampling.

  • noise: the observation noise variance, or nothing when fit_hyperparams returns one. A noise returned by fit_hyperparams replaces it, with a warning the first time if it was a number; the one in use is ho.sampler.noise[].

  • n_initial: how many trials initial draws before next_point is used. No further trial is proposed until all of them have finished; next_point then takes over from those that completed, with a warning if that is fewer than n_initial.

  • initial: the sampler that draws the initial trials, SobolSampler by default, or RandomSampler, or LHSampler when strict_initialization is true.

  • fit_hyperparams(X, y): called before each conditioning; return either the GP to condition on, e.g. one with refitted kernel hyperparameters, or a (gp, noise) pair to refit the noise variance too. When nothing, gp is used as given.

  • standardize(y): transform the observed values before fit_hyperparams and conditioning; the default shifts and scales them to mean 0 and standard deviation 1. When nothing, they are used as given.

  • strict_initialization: when false, each initial trial that does not complete gets an extra trial from initial instead, with a warning, until n_initial have completed; the unsuccessful ones stay in the results, and new proposals wait only while the initial trials still running could complete the set.

next_point, fit_hyperparams and standardize are saved in checkpoints by name, so pass named functions or callable structs such as ThompsonSampling.

BigHOPs.Hyperband Type
julia
Hyperband(; R, η=3, r_min=1, iterations=1, inner=RandomSampler())

Successive halving over brackets that start at resource levels from r_min up to R: after each rung the best 1/η of trials continue with η times the resource, and a rung must finish before any of its trials are promoted (Li et al., 2018, https://doi.org/10.48550/arXiv.1603.06560). iterations repeats the whole schedule, inner draws the starting configurations, and the objective receives the resource level as p.r.

When every open bracket is waiting on results and the executor has spare capacity, the next bracket starts, from the next iteration if needed; earlier brackets keep priority for every new trial.

BigHOPs.LHSampler Type
julia
LHSampler(; rng=StableRNG(1))

Draw all n trials up front as a Latin hypercube, which spreads them evenly along every hyperparameter. Warns if n is too small to cover every combination of discrete values. Each LHSampler() can back only one Hyperoptimizer.

BigHOPs.SobolSampler Type
julia
SobolSampler(; rng=StableRNG(1))

Draw each trial's hyperparameters as the next point of a Sobol sequence, moved by one random offset drawn from rng and wrapped around at 1, so successive trials spread over the space more evenly than independent random draws. Like RandomSampler, it generates points as they are asked for and needs no fixed number of trials; after any power-of-2 number of trials, each hyperparameter's range is covered evenly.

source
BigHOPs.Stateful Type
julia
Stateful(f)

Wrap an objective that carries state between trials: f(p; pre_artefact) returns (value, post_artefact). When Hyperband or ASHA promote a trial to a higher resource level, the promoted trial gets the earlier post_artefact as its pre_artefact, so it can resume rather than restart; otherwise pre_artefact is nothing.

source
BigHOPs.ThompsonSampling Type
julia
ThompsonSampling(n_candidates; jitter)

A next_point for GPSampler: draw the GP posterior jointly at n_candidates candidate points and return the one where the draw is lowest (Kandasamy et al., 2018, https://proceedings.mlr.press/v84/kandasamy18a.html). The candidates are Sobol points moved by one random offset, drawn afresh from rng on every call, and wrapped around at 1; a power-of-2 number of them covers each hyperparameter exactly evenly. jitter is the variance added to the draw's covariance so that it can be factorized.

source
BigHOPs.Threaded Type
julia
Threaded(max_concurrency=Threads.nthreads())

Evaluate up to max_concurrency trials at once, as tasks spread over Julia's threads. Start Julia with --threads=N for real parallelism; on one thread the trials only interleave.

BigHOPs.run! Method
julia
run!(ho; executor=Serial(), save_every=nothing, save_path=nothing, show_progress=true)

Evaluate trials until the target is reached or the sampler is exhausted, using executor (Serial, Threaded or DistributedQueue). Given save_path, ho is checkpointed when the run ends, and also after every save_every trials if that is set; resume with load_hyperoptimizer.

source
BigHOPs.save_hyperoptimizer Method
julia
save_hyperoptimizer(ho, path)

Write ho, without its objective, to path as a JLD2 checkpoint, storing each trial's error as its printed text. It is written to a temporary file first and then moved into place, so a crash mid-save leaves the previous checkpoint intact.

source
