# Contributing

`BigHOPs.jl` has a set of functions which should be implemented for any new executor or sampler, we describe the skeleton below. If you would like to request or contribute plotting or other kinds of functionality, [open an issue](https://github.com/dom-linkevicius/BigHOPs.jl/issues/new/choose).

## Contributing an executor

An executor decides how trials are evaluated. `run!` calls `start!` and `shutdown!` at the start and end of a run, hands it trials with `submit!` while `capacity` is positive, and collects the finished `(entry, outcome)` pairs with `poll`.

```julia
mutable struct MyExecutor <: BigHOPs.AbstractExecutor
    ...
end

BigHOPs.start!(executor::MyExecutor, ho) = ...
BigHOPs.submit!(executor::MyExecutor, entry, f) = ...
BigHOPs.poll(executor::MyExecutor) = ...
BigHOPs.capacity(executor::MyExecutor) = ...
BigHOPs.shutdown!(executor::MyExecutor) = ...
```

## Contributing a sampler

A sampler decides which candidates are tried. Called as `sampler(domains, runs)`, it returns one value in $[0, 1]$ per hyperparameter, which the domains decode. `init` prepares it for a search of `n` trials, `create_run_entry` builds each new trial's `RunEntry`, `on_tell!` updates it with each finished trial, and `exhausted` and `blocked` tell `run!` when it can propose nothing, for good or until pending trials finish.

```julia
struct MySampler <: BigHOPs.Sampler
    ...
end

(sampler::MySampler)(domains, runs) = ...
BigHOPs.init(sampler::MySampler, domains, n) = ...
BigHOPs.create_run_entry(sampler::MySampler, ho, id, params, unit_params) = ...
BigHOPs.on_tell!(sampler::MySampler, runs, entry) = ...
BigHOPs.exhausted(sampler::MySampler, ho) = ...
BigHOPs.blocked(sampler::MySampler, ho) = ...
```
